# Petgram

> Platforma społecznościowa dla opiekunów i miłośników zwierząt.

Petgram skupia się na publikowaniu, przeglądaniu i porządkowaniu treści związanych wyłącznie ze zwierzętami. Celem projektu jest stworzenie spokojnej, wyspecjalizowanej przestrzeni zamiast ogólnego serwisu społecznościowego.

## ✨ Główne założenia

- 📱 feed z pionowym przewijaniem,
- 🔎 wyszukiwanie treści po tagach, gatunku, rasie i lokalizacji,
- 🖼️ szybkie tworzenie postów ze zdjęciami i wideo,
- 👤 profile użytkowników i profile pupili,
- 🎨 prosty interfejs nastawiony na wygodne korzystanie na telefonie i komputerze,
- ⭐ opcje obserwowania, zapisywania i zgłaszania treści.
